Project Overview

Standard oncology diagnostics rely on invasive procedures or complex imaging. This project explores how interpretable Machine Learning algorithms can assist in early preliminary risk evaluation using standard, non-invasive clinical blood tests.

Data Source

We utilized the open-source Breast Cancer Coimbra Dataset from the UCI Machine Learning Repository. It comprises 116 clinical patient records featuring 9 key metabolic indicators, including Fasting Glucose, Insulin, HOMA, Leptin, Adiponectin, Resistin, and MCP-1.

Methodology & Model Tuning

Our backend employs a DecisionTreeClassifier from Scikit-Learn. To optimize prediction reliability on small medical datasets, we implemented 5-Fold Stratified Cross-Validation alongside GridSearchCV hyperparameter tuning to find optimal decision tree depths and split criteria.
